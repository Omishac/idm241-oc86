Poppi Soda: Visit the site

TRIGGERS:

  • Hover On/Off Buy now Button
  • Click Buy Now Button
  • Click On/Off Soda Icon: Active
  • Click On/Off Soda Icon: Default
  • Hover On/Off Cherry Soda Label
  • Mouse down/up Soda Image

RULES:

Hover Buy Button

  • Hover On- Cursor changes to finger and button inverts color to red and text changes to purple
  • Hover Off- Cursor changes back to pointer and button returns to original purple button color and red text

Click Buy Button

  • Click- User clicks on button and a loading page opens with purple background and red bubbles floating up before going to the amazon page opens

Click Soda Icon: Active

  • Click On- Soda card shakes up and shows the back of the can
  • Click Off- Soda card shakes up and shows the front of the can

Click Soda Icon: Default

  • Click On- Soda card shakes up and shows the front of the can
  • Click Off- Soda card shakes up and shows the back of the can

Hover Cherry Soda Label

  • Hover On- Cursor changes to finger and product card inverts to gradient being purple to red
  • Hover Off- Cursor changes back to pointer product card reverts to original red to purple gradient color

Mouse Down/Up Soda Image

  • Mouse Down- The soda image shakes for the time the user has their mouse down
  • Mouse Up- The user is taken to the Cherry Cola Product page
