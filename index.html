Buy Now Button

TRIGGERS:

Buy Now Button

  • Hover On
  • Hover Off
  • Click

RULES:

Buy Now Button

  • Hover On- Cursor changes to finger and button inverts color to red
  • Hover Off- Cursor changes back to pointer and button returns to original purple color
  • Click- User clicks on button and a loading page opens with purple background and bubbles floating from bottom of screen to the top then the amazon page opens

  • Mode: Buy now button switching colors on Hover on/off
